# RoomCheck - Week 1: Setup Dasar & Pengenalan React Native

## Deskripsi Tugas
Pada pertemuan pertama (Week 1), mahasiswa mempelajari dasar-dasar ekosistem pengembangan mobile menggunakan React Native dan Expo sesuai modul `MODUL 0 - SETUP DASAR`.

### Capaian:
1. Instalasi Node.js LTS dan package manager (npm).
2. Instalasi Expo CLI dan inisialisasi template React Native TypeScript (`create-expo-app`).
3. Memahami struktur file utama (`package.json`, `app.json`, `tsconfig.json`, `index.ts`, `App.tsx`).
4. Menjalankan aplikasi perdana di emulator / perangkat fisik melalui **Expo Go**.

### Cara Menjalankan:
```bash
cd RoomCheck/Week-1
npm install
npx expo start
```
Buka aplikasi **Expo Go** pada smartphone dan pindai QR code yang tampil di terminal.
